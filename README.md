# CURSOR

Одностраничное веб-приложение сценария съёмки: в шапке страницы и в метаданных — **CURSOR** (имя воркспейса/чата в Cursor). Продуктовая подпись сценария — **Sam Scenes**. **На GitHub** всё лежит в репозитории **`SamBruev/abakan-script`**: это один сайт из корня репо — открываете ссылку Pages ниже, и видите приложение (GitHub сам подхватывает главную страницу в корне).

- Исходники (источник правды): **`SamScenes/`**
- Копия для выкладки / локальное зеркало: **`abakan-script/`** — тот же сайт и те же ресурсы рядом с ним

**Сайт:** [sambruev.github.io/abakan-script/](https://sambruev.github.io/abakan-script/)

Имя репозитория **`abakan-script`** совпадает с сегментом пути в URL Pages; менять необязательно.

После клонирования один раз включите автоотправку коммитов на GitHub (чтобы Pages не отставал):

```bash
git config core.hooksPath .githooks
```

Тогда каждый локальный `git commit` на ветке `main` сразу выполняет `git push origin main`.
