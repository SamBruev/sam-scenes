# Sam Scenes

Одностраничное веб-приложение сценария съёмки **Sam Scenes** — так мы называем проект в чате и в интерфейсе. **На GitHub** всё по-прежнему лежит в репозитории **`SamBruev/abakan-script`**, главная страница — это файл **`index.html`** в корне репо (его и публикует GitHub Pages).

- Исходники (источник правды): **`SamScenes/`**
- Копия для выкладки / локальное зеркало: **`abakan-script/`** (тот же `index.html` и ресурсы)

**Сайт:** [sambruev.github.io/abakan-script/](https://sambruev.github.io/abakan-script/)

Имя репозитория **`abakan-script`** совпадает с сегментом пути в URL Pages; менять необязательно.

После клонирования один раз включите автоотправку коммитов на GitHub (чтобы Pages не отставал):

```bash
git config core.hooksPath .githooks
```

Тогда каждый локальный `git commit` на ветке `main` сразу выполняет `git push origin main`.
