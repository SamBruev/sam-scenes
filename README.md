# Sam Scenes

Веб-приложение сценария съёмки **Sam Scenes** (ранее в коде и репозитории фигурировало имя abakan-script). Локальная папка проекта — **SamScenes/**.

Сайт на GitHub Pages: [sambruev.github.io/abakan-script/](https://sambruev.github.io/abakan-script/) (URL сохраняется, даже если репозиторий на GitHub по-прежнему называется `abakan-script`).

После клонирования один раз включите автоотправку коммитов на GitHub (чтобы Pages не отставал):

```bash
git config core.hooksPath .githooks
```

Тогда каждый локальный `git commit` на ветке `main` сразу выполняет `git push origin main`.
