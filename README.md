# Sam Scenes

Одностраничное веб-приложение сценария съёмки **Sam Scenes** — так мы называем проект **в этом чате** и в документации. Раньше в путях и на GitHub фигурировало имя **abakan-script** / «Абакан-скрипт»; **публичный URL сайта сохранён**.

- Исходники (источник правды): **`SamScenes/`**
- Зеркало для выкладки на Pages: **`abakan-script/`** (тот же `index.html` и ресурсы)

**Сайт:** [sambruev.github.io/abakan-script/](https://sambruev.github.io/abakan-script/)

Репозиторий GitHub: `SamBruev/abakan-script` (переименование репозитория — отдельно; ссылку Pages менять не обязательно).

После клонирования один раз включите автоотправку коммитов на GitHub (чтобы Pages не отставал):

```bash
git config core.hooksPath .githooks
```

Тогда каждый локальный `git commit` на ветке `main` сразу выполняет `git push origin main`.
