# iOS PWA — чеклист для Sam / Opus

**Устройство:** iPhone, приложение **на рабочем столе** (standalone), не только Safari.  
**После деплоя:** полностью закрыть из переключателя → открыть с интернетом → дождаться v403+ в build-info.

---

## Обязательный минимум (15–20 мин)

- [ ] **Версия:** build-info = v403+
- [ ] **Hub / план дня:** свёрнуты при загрузке; один tap открывает/закрывает без двойного щелчка
- [ ] **F1 Шотлист:** сменить сценарий свайпом → добавить «№» в шотлисте → удалить номер — работает без reload
- [ ] **Суфлёр ×:** открыть суфлёр → закрыть × одним тапом (standalone!)
- [ ] **Суфлёр keys:** назначить play/stop/hold → проверить в overlay
- [ ] **Delete scene:** confirm → анимация fade/collapse → ↶ Назад откатывает
- [ ] **«Важно»:** все чекбоксы → одна «Всё под контролем!» в блоке «Важно»; **нет** под «Анна Непряхина»
- [ ] **Scroll top:** логотип SAM BRUEV плавно появляется, без рывка
- [ ] **Ассистент:** тап по строке «Ассистент» → drawer; tap outside закрывает
- [ ] **SW update:** после push — закрыть PWA → открыть online → новая версия без потери данных
